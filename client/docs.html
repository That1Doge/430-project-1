Pokedex API Documentation

Every endpoint returns JSON. Data lives in memory, so anything added or edited resets when the server restarts

/getPokemon GET HEAD

Query Params

name (optional) Type: string - Part of a Pokémon's name to filter by. Capitalization is ignored.

type (optional) Type: string - A type to filter by, like Fire.

weakness (optional) Type: string - A type the Pokémon must be weak to.

limit (optional) Type: number - The most results to return. Must be a whole number of 1 or more.

Returns

A JSON object with the number of matches and an array of Pokémon objects.
Format: { count: number, results: [{ id: number, num: string, name: string, img: string, type: [string], height: string, weight: string, weaknesses: [string], next_evolution?: [{ num: string, name: string }] }] }

Examples

Request: /getPokemon?type=Fire&limit=1

Result: { count: 1, results: [{ id: 4, num: '004', name: 'Charmander', type: ['Fire'], height: '0.61 m', weight: '8.5 kg', weaknesses: ['Water', 'Ground', 'Rock'], next_evolution: [{ num: '005', name: 'Charmeleon' }, { num: '006', name: 'Charizard' }], img: '...' }] }

Request: /getPokemon?limit=0

Result: 400 Error (limit must be 1 or more)

/getPokemonById GET HEAD

Query Params

id (required) Type: number - The id of the Pokémon.

Returns

A JSON Pokémon object.
Format: { id: number, num: string, name: string, img: string, type: [string], height: string, weight: string, weaknesses: [string], next_evolution?: [{ num: string, name: string }] }

Examples

Request: /getPokemonById?id=2

Result: { id: 2, num: '002', name: 'Ivysaur', type: ['Grass', 'Poison'], height: '0.99 m', weight: '13.0 kg', weaknesses: ['Fire', 'Ice', 'Flying', 'Psychic'], next_evolution: [{ num: '003', name: 'Venusaur' }], img: '...' }

Request: /getPokemonById

Result: 400 Error (Missing id)

Request: /getPokemonById?id=99999

Result: 404 Error (Pokémon Doesn't Exist)

/getTypes GET HEAD

Query Params

No Supported Params

Returns

A JSON object with every type and how many Pokémon have it, sorted by type name.
Format: { types: [{ type: string, count: number }] }

Examples

Request: /getTypes

Result: { types: [{ type: 'Bug', count: 12 }, { type: 'Dragon', count: 3 }, ...] }

/getEvolutions GET HEAD

Query Params

id (required) Type: number - The id of the Pokémon.

Returns

A JSON object listing what the Pokémon evolves from and into. Either list may be empty.
Format: { id: number, name: string, evolvesFrom: [{ num: string, name: string }], evolvesInto: [{ num: string, name: string }] }

Examples

Request: /getEvolutions?id=2

Result: { id: 2, name: 'Ivysaur', evolvesFrom: [{ num: '001', name: 'Bulbasaur' }], evolvesInto: [{ num: '003', name: 'Venusaur' }] }

Request: /getEvolutions

Result: 400 Error (Missing id)

/addPokemon POST

Supported Body Formats

application/json application/x-www-form-urlencoded

Body Params

name (required) Type: string - The Pokémon's name. Must be unique, ignoring capitalization.

type (required) Type: string or [string] - One or two types, as a comma separated string or a JSON array.

height (optional) Type: string or number - Height in meters, like 1.2. Stored as '1.2 m'.

weight (optional) Type: string or number - Weight in kilograms, like 45. Stored as '45 kg'.

weaknesses (optional) Type: string or [string] - Weak-to types, in the same format as type.

img (optional) Type: string - An image URL.

Returns

A 201 status and a JSON Pokémon object for the new Pokémon. The server picks its id and num.
Format: { id: number, num: string, name: string, img: string, type: [string], height: string, weight: string, weaknesses: [string] }

Examples

Request: /addPokemon

Body: { name: 'Voidling', type: 'Ghost,Dragon', height: '1.2', weight: '30' }

Result: 201 { id: 152, num: '152', name: 'Voidling', img: '', type: ['Ghost', 'Dragon'], height: '1.2 m', weight: '30 kg', weaknesses: [] }

Request: /addPokemon

Body: { name: 'Voidling' }

Result: 400 Error (Missing type)

Request: /addPokemon

Body: { name: 'Pikachu', type: 'Electric' }

Result: 409 Error (Name Already Exists)

/updatePokemon POST

Supported Body Formats

application/json application/x-www-form-urlencoded

Body Params

id (required) Type: number - The id of the Pokémon to change.

name (optional) Type: string - A new name. Must stay unique.

type (optional) Type: string or [string] - New types, as a comma separated string or a JSON array.

height (optional) Type: string or number - New height in meters.

weight (optional) Type: string or number - New weight in kilograms.

weaknesses (optional) Type: string or [string] - New weak-to types.

img (optional) Type: string - A new image URL.

At least one optional param must be sent. Only the params you send are changed.

Returns

A 204 status with no body when the Pokémon was updated.

Examples

Request: /updatePokemon

Body: { id: 25, weight: '6.2 kg' }

Result: 204 (No Content)

Request: /updatePokemon

Body: { id: 25 }

Result: 400 Error (Nothing to Change)

Request: /updatePokemon

Body: { id: 99999, name: 'Fake' }

Result: 404 Error (Pokémon Doesn't Exist)

Errors and Headers

Errors are returned as JSON in this format: { message: string, id: string}

Any URL that does not exist returns 404. Every response includes Content-Type and Content-Length headers, and HEAD requests return the same headers as GET without a body.
